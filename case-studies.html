NeuUX AI

An AI-powered UX system designed to reduce the time between idea and structured product thinking.

Context Problem Approach Solution Key Decisions Impact

Context

Early-stage teams often struggle to translate ideas into clear UX artifacts, slowing down decision-making.

Problem

UX processes are fragmented, manual, and time-consuming—especially during early product stages.

Approach

Designed a modular AI system that converts product ideas into structured UX outputs through guided interaction.

Solution

A UX intelligence assistant that generates:

  • Personas
  • Journey maps
  • UX strategies

Built around a conversational interface to support flexible thinking.

Key Decisions

  • Treated UX as a system, not isolated deliverables
  • Prioritized clarity over feature complexity
  • Designed modular outputs for scalability

Impact

Reduced decision ambiguity in early-stage product workflows. Teams moved from idea to structured UX artifact significantly faster, with less back-and-forth.

02 / 04

MEDICO

A system designed to simplify patient flow in hospitals by replacing manual queue management.

Context Problem Approach Solution Key Decisions Impact

Context

Hospitals rely on inefficient, manual processes that create confusion and long waiting times.

Problem

Patients lack visibility and structure in OP processes, leading to frustration and delays.

Approach

Mapped the entire patient journey—from registration to consultation—and identified friction points.

Solution

Designed a digital OP system with:

  • Structured token generation
  • Department-based flow
  • Admin control for hospitals

Key Decisions

  • Focused on reducing cognitive load for patients
  • Simplified admin workflows for scalability
  • Designed for real-world hospital constraints

Impact

Eliminated unstructured waiting by introducing a token-based flow system. Patients gained real-time visibility; hospital staff gained a controllable, scalable queue system.

Beyond Syllabus

Context Problem Approach Solution Key Decisions Impact

Context

Students often rely on static curricula that do not reflect current industry needs.

Problem

Lack of personalized, flexible learning support.

Approach

Focused on building a system that adapts to user intent rather than fixed content paths.

Solution
